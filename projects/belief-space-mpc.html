Learning-Based Control via Kalman Filtering and Belief-Space MPC

Online parameter estimation and uncertainty-aware predictive control for systems with uncertain dynamics.

Overview

This project investigates how online system identification can be integrated directly with Model Predictive Control (MPC). Rather than assuming that the plant model is perfectly known, uncertain model parameters are estimated recursively using a Kalman Filter (KF), and the prediction model used by the controller is updated as new information becomes available.

The framework is developed progressively in three stages. First, the KF is used as a parameter estimator. Next, the estimated parameters are used to update the MPC model online. Finally, estimator uncertainty itself is incorporated into the optimization problem, leading to Belief-Space MPC, where the controller considers both control performance and future uncertainty.

Main idea: the controller should not only use what has already been learned about the system; its control actions can also influence what will be learned from future measurements.

Uncertain System & Parameter Estimation

Consider a dynamical system whose behavior depends on an uncertain parameter vector \(\theta\). The unknown parameters are incorporated into the estimation problem as additional states. A slowly varying parameter model can be written as

\[ \theta_{k+1}=\theta_k+w_{\theta,k}. \]

At every sampling instant, the Kalman Filter combines model predictions with measurements and produces

\[ \hat{\theta}_{k|k},\qquad P_{k|k}. \]

The vector \(\hat{\theta}_{k|k}\) represents the current parameter estimate, while \(P_{k|k}\) quantifies the remaining uncertainty. The estimator therefore provides both a model estimate and a measure of confidence in that estimate.

Stage 1 — Kalman Filter for Online Parameter Identification

The first stage focuses on estimation. Measurements from the physical system are processed recursively through the prediction–correction structure of the Kalman Filter.

The prediction step generates a prior parameter estimate and covariance. The correction step then incorporates the new measurement to produce the posterior estimate and covariance.

\[ \text{Prior belief} \longrightarrow \text{Measurement update} \longrightarrow (\hat{\theta}_{k|k},P_{k|k}). \]

At this stage, estimation and control remain largely separated: the estimator learns the uncertain dynamics, but parameter uncertainty does not yet influence how the controller selects its input.

Stage 2 — Adaptive Model Predictive Control

In the second stage, the estimated parameters update the MPC prediction model. For example, if the system matrix depends on the uncertain parameters,

\[ A_k=A\!\left(\hat{\theta}_{k|k}\right), \]

with the same principle applying to \(B_k\), \(C_k\), or other model components when they depend on \(\theta\). The controller therefore operates with an evolving model rather than a fixed nominal model.

This improves prediction as the parameter estimates converge. However, the controller still optimizes primarily using the current best estimate. The covariance \(P_k\) is available from the estimator but does not yet directly influence the MPC objective.

Key distinction: updating MPC with \(\hat{\theta}_k\) creates an adaptive MPC. To obtain a belief-space controller, the uncertainty \(P_k\) must also become part of the predictive optimization.

Stage 3 — Belief-Space Model Predictive Control

The final stage augments conventional MPC with the evolution of estimator uncertainty. The controller predicts not only the future physical states, but also the future belief about the uncertain parameters:

\[ b_k=\left(\hat{\theta}_{k|k},P_{k|k}\right). \]

Over the prediction horizon, candidate control sequences generate future state trajectories and corresponding covariance trajectories \(P_{k+i|k}\). Since future measurements depend on the trajectory of the system, different control actions can lead to different levels of information about the uncertain parameters.

The MPC objective can therefore include an uncertainty penalty:

\[ J= J_{\mathrm{tracking}} +J_{\Delta u} +J_u +\lambda J_{\mathrm{uncertainty}}. \]

For example, uncertainty can be quantified through

\[ J_{\mathrm{uncertainty}} = \sum_{i=1}^{N_p}\operatorname{tr}(P_{k+i|k}), \]

or through an information-volume criterion based on \(\log\det(P_{k+i|k})\). The weighting parameter \(\lambda\) controls the trade-off between conventional control objectives and uncertainty reduction.

Control vs. Learning

This formulation introduces an important interaction between control and learning. A control action that gives the best immediate tracking performance may not necessarily generate measurements that are informative about the uncertain parameters.

Conversely, another input may excite the system in a way that reduces parameter uncertainty, improving the model and potentially improving control performance later in the prediction horizon.

Control objective: regulate the physical system while balancing exploitation of the current model with information gathering for improved future predictions.

Implementation Framework

At each sampling instant, the estimator processes the latest measurements and updates both the parameter estimate and covariance. The physical prediction model is reconstructed using \(\hat{\theta}_{k|k}\).

The MPC optimization then propagates the predicted physical dynamics together with the covariance dynamics over the prediction horizon. The optimized input sequence reflects both expected control performance and the evolution of model uncertainty. Only the first optimized input is applied, and the complete estimation and optimization procedure is repeated at the next sampling instant.

\[ \text{Measure} \rightarrow \text{Estimate }(\hat{\theta},P) \rightarrow \text{Update Model} \rightarrow \text{Predict Belief} \rightarrow \text{Optimize} \rightarrow \text{Apply }u. \]

Key Objectives & Takeaways

  • Recursive online parameter identification using a Kalman Filter rather than relying on a fixed nominal model.
  • Online reconstruction of the MPC prediction model using the latest parameter estimates, providing an adaptive MPC architecture.
  • Explicit propagation of estimator covariance over the MPC prediction horizon to represent future parameter uncertainty.
  • Integration of uncertainty measures such as \(\operatorname{tr}(P)\) or \(\log\det(P)\) into the objective, producing an uncertainty-aware / belief-space controller.
  • Investigation of the trade-off between immediate control performance and control actions that improve the quality of future model estimates.

Research Direction

Ongoing research project on learning-based and uncertainty-aware predictive control, with emphasis on combining recursive parameter estimation, adaptive model updates, and Belief-Space MPC.
