Constraint-Aware Gaussian-Process Feedback Linearization with MPC

Extending GP-based feedback linearization with actuator-constraint handling and an explicit characterization of the residual uncertainty caused by imperfect feedback linearization.

Overview

Feedback linearization provides a powerful way to transform nonlinear system dynamics into an equivalent linear form, but its effectiveness depends strongly on accurate knowledge of the nonlinear model. Gaussian Processes (GPs) provide a data-driven alternative by learning the unknown nonlinear dynamics while also quantifying uncertainty associated with the learned model.

This project extends the GP-based feedback linearization framework by integrating the approximately linearized system with Model Predictive Control (MPC). The proposed architecture addresses two practical issues: physical actuator constraints and the residual uncertainty resulting from imperfect GP-based feedback linearization.

Main idea: use GP posterior means to construct the feedback-linearizing controller, map physical actuator limits into admissible bounds on the MPC virtual input, and use GP posterior uncertainty to quantify the mismatch between the nominal linear MPC model and the actual approximately linearized system.

GP-Based Feedback Linearization

Consider a full-state linearizable SISO nonlinear system in controllable canonical form, with unknown drift and input-gain functions:

\[ \dot{x}_1=x_2,\quad \dot{x}_2=x_3,\quad \ldots,\quad \dot{x}_n=f(x)+g(x)u. \]

The unknown functions \(f(x)\) and \(g(x)\) are modeled using Gaussian Processes. Their posterior means provide the model estimates

\[ \hat f(x)=\mu_f(x),\qquad \hat g(x)=\mu_g(x), \]

while \(\sigma_f(x)\) and \(\sigma_g(x)\) quantify the corresponding posterior uncertainty. Following the GP feedback-linearization framework, the physical control input is

\[ u=\frac{1}{\hat g(x)}\left[-\hat f(x)+\nu\right], \]

where \(\nu\) is the virtual input of the approximately linearized system. Instead of generating \(\nu\) through a conventional linear feedback law, this project uses a linear MPC so that constraints can be explicitly incorporated into the control design.

Approximately Linearized Dynamics

If the GP estimates were exact, feedback linearization would completely cancel the nonlinear dynamics. With imperfect estimates, however, a residual modeling error remains. The resulting dynamics can be expressed as

\[ \dot{x}=Ax+B\nu+B d_{\mathrm{GP}}, \]

where

\[ d_{\mathrm{GP}} = f-\frac{g}{\hat g}\hat f + \left(\frac{g}{\hat g}-1\right)\nu. \]

For perfect estimates, \(\hat f=f\) and \(\hat g=g\), so \(d_{\mathrm{GP}}=0\). After discretization, the nominal prediction model used by the linear MPC is

\[ x_{k+1}=A_d x_k+B_d\nu_k, \]

whereas the actual approximately linearized dynamics contain the additional effect of \(d_{\mathrm{GP},k}\). This term represents the discrepancy between the ideal linear model assumed by MPC and the behavior produced by imperfect GP-based feedback linearization.

Actuator Constraint Mapping

A key challenge is that MPC optimizes the virtual input \(\nu\), while the physical actuator is constrained in terms of the actual input \(u\):

\[ u_{\min}\leq u\leq u_{\max}. \]

Rearranging the GP feedback-linearization control law gives

\[ \nu=\hat f(x)+\hat g(x)u. \]

For \(\hat g(x)>0\), the physical actuator limits can therefore be mapped directly into state-dependent bounds on the virtual input:

\[ \hat f(x)+\hat g(x)u_{\min} \leq \nu \leq \hat f(x)+\hat g(x)u_{\max}. \]

These admissible bounds are updated using the current GP estimates and supplied to the linear MPC. Importantly, imperfect GP estimates affect the quality of feedback linearization, but do not invalidate the algebraic actuator-bound mapping for the implemented control law.

Constraint-aware MPC: the physical actuator constraint is converted into an admissible interval for the virtual input optimized by the linear MPC.

GP Uncertainty & Residual Linearization Error

The second part of the project uses the uncertainty information provided by Gaussian Processes to characterize the error remaining after approximate feedback linearization.

Defining \(\Delta f=f-\hat f\) and \(\Delta g=g-\hat g\), the residual error can be expressed compactly as

\[ d_{\mathrm{GP}}=\Delta f+u\,\Delta g. \]

Using three posterior standard-deviation intervals,

\[ -3\sigma_f(x)\leq\Delta f\leq3\sigma_f(x), \qquad -3\sigma_g(x)\leq\Delta g\leq3\sigma_g(x), \]

together with the actuator bounds, a conservative symmetric uncertainty bound is

\[ |d_{\mathrm{GP}}| \leq 3\sigma_f(x)+3\sigma_g(x)u_{\mathrm{abs}}, \qquad u_{\mathrm{abs}}=\max\{|u_{\min}|,|u_{\max}|\}. \]

This creates a direct connection between GP posterior uncertainty and the uncertainty affecting the nominal linear prediction model used by MPC. Regions with greater GP uncertainty consequently correspond to a larger possible discrepancy from ideal feedback-linearized behavior.

Toward Robust GP–FL–MPC

The uncertainty characterization allows the approximately linearized dynamics to be viewed as a nominal linear system subject to a bounded residual term:

\[ x_{k+1}=A_d x_k+B_d\nu_k+B_d d_{\mathrm{GP},k}. \]

This representation provides a basis for incorporating learned GP uncertainty into robust prediction, constraint tightening, or performance analysis. Since GP uncertainty is state dependent, a rigorous multi-step robust formulation requires either a uniform uncertainty bound over the relevant operating region or propagation of the state-dependent uncertainty throughout the MPC prediction horizon.

The resulting architecture connects data-driven nonlinear modeling with a structured linear predictive-control problem: the GP learns the nonlinear dynamics and reports its confidence, feedback linearization creates the nominal linear representation, and MPC handles optimization and actuator limitations.

Key Contributions & Objectives

  • Extend GP-based feedback linearization by replacing the conventional virtual-input controller with Model Predictive Control.
  • Map physical actuator constraints into state-dependent admissible bounds on the virtual input optimized by MPC.
  • Express the error caused by imperfect feedback linearization as a matched residual uncertainty acting on the nominal linearized dynamics.
  • Use GP posterior standard deviations to construct an explicit bound on the residual linearization error.
  • Establish a foundation for future robust and uncertainty-aware MPC formulations based on learned, state-dependent model uncertainty.
